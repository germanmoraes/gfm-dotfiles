# gfm-dotfiles

Configuração pessoal do Arch Linux com Hyprland e Quickshell.

## Estrutura

- `config/` — configurações do sistema e da interface
- `packages/` — dependências declaradas
- `local/bin/` — executáveis e AppImages locais
- `scripts/` — scripts de instalação e manutenção

## Instalação

A instalação será realizada pelo script:

```bash
./scripts/install.sh
